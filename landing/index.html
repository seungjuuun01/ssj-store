설치 방법

한 번만 저장소를 추가하면, 이후 업데이트는 F-Droid가 자동으로 알려줍니다.

  1. 위의 F-Droid 설치 버튼으로 F-Droid 클라이언트를 설치
  2. F-Droid → 설정 → 저장소 → + → 위 주소 붙여넣기 (주소 복사 버튼 이용)
  3. "최신 정보 업데이트" → 목록에서 원하는 앱 설치
