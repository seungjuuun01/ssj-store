📦 HackMin Store

HackMin 앱을 설치·업데이트하는 자체 F-Droid 저장소입니다.

설치 방법

  1. F-Droid 클라이언트 설치
  2. F-Droid → 설정 → 저장소 → + 버튼 → 아래 주소 추가

https://geonha0507.github.io/hackmin-store/repo

추가 후 "최신 정보 업데이트"를 누르면 HackMin Deliver / Rider 앱이 목록에 나타납니다. 앱은 새 버전이 올라올 때마다 F-Droid가 자동으로 업데이트 알림을 표시합니다.

  • HackMin Rider (com.hackmin.connect)
